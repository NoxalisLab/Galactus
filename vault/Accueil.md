# Accueil

Ce coffre est la mémoire de travail de Galactus. Il n'explique pas
l'application, il explique **comment travailler avec elle**, métier par métier.

L'assistant lit ces notes avec `obsidian_search` et `obsidian_read`, dans une
fenêtre de 8192 tokens. Chaque note est donc courte et autonome. La règle
d'écriture est dans [[Conventions du coffre]].

## En une minute

1. Ouvre la note de ton métier dans `Professions/` : elle donne les workflows,
   le modèle à lancer et les vérifications.
2. Lis [[Bien demander]] et [[Vérifier avant de croire]]. Ces deux notes valent
   plus que toutes les autres réunies.
3. Choisis ton modèle avec [[Choisir un modèle]] : la vitesse dépend de la RAM
   de ce Mac, pas d'un classement en ligne.
4. Règle ton niveau d'autonomie : [[Niveaux d'autonomie]].
