# Galactus Desktop v0.1.3

A native macOS app for the Galactus MoE engine: run certified open-weight
Mixture-of-Experts models fully on-device, including models several times
larger than your RAM, and let them work on your files, shell and notes behind
a strict permission gate.

Designed and developed by Noxalis Lab.

This release is about depth: thirty packaged skills instead of ten, a starter
Obsidian vault inside the bundle, bundled Rust tooling, a resizable workspace,
and a model policy enforced against measured hardware rather than declared
intent.

## Thirty skills, with their provenance

Twenty new skills join the ten already shipped, covering development (senior
dev, code review, methodical debugging, refactoring, writing tests, API
design, SQL, regular expressions, git surgery), operations (Docker,
Kubernetes, Terraform, remote servers over SSH, production incidents, log
analysis, performance profiling), data and AI, and professional work
(document analysis, sourced research, professional writing, technical
translation, meeting minutes, spreadsheets, LaTeX, accessibility, UI/UX,
portfolio tracking, sensitive data, mac automation, local prompting).

Each is a procedure with commands and a verification step, sized for a small
context window. Fifteen adapt public material; the five upstream sources are
MIT and are credited in `NOTICE`, with per-source commit, SPDX id and what was
taken recorded in `docs/skills-sources.md`. Sources without a licence file, or
under GPL, AGPL, CC-BY-SA or CC-BY-NC, were rejected and are listed with the
reason.

Tripling the skill count tripled a cost nobody had measured: the catalogue is
injected into the system prompt on every request, one line per skill. The
descriptions explained what a skill does, when the catalogue only needs to say
when to trigger it. Rewritten as routing triggers, the catalogue fell from
2161 tokens to 957, from 26.4% of an 8192-token window to 11.7%, giving 1205
tokens per request back to the conversation. The guard rails some descriptions
carried were verified present in their bodies before being dropped from the
summary line.

`scripts/check-skills.py` enforces the invariants: tool names checked against
the real twenty-one, tool names from other runtimes rejected everywhere
including code blocks, no em dashes, frontmatter limited to `name` and
`description` with `name` matching its directory.

## A starter vault in the bundle

The app now ships fifty notes, seeded on first launch and never overwritten
afterwards: conventions, working practices and trade-specific notes. Connect
it, or your own Obsidian vault, and the agent reads and writes notes with the
same diff discipline as files. The Constellation view renders the wikilink
graph as a navigable 3D starfield.

## Workspace and editor

The workspace panes resize by pointer and by keyboard, keeping both their own
bounds and the reserved workspace visible, and persist only committed sizes so
a corrupt setting cannot wedge the layout.

The Code view gains an automatic tab layer, a restored-root path and a review
gate over proposed edits. Everything the model writes inside the workspace
stays a proposal: a pending diff accepted or rejected hunk by hunk, and only
accepted hunks are ever written.

Auto Tab offers inline completions generated by your own local model, taking
6000 characters before the caret and 2000 after as context, accepted with Tab.
Prose is refused and the suggestion is forced to be insertion-only, so a
talkative model cannot drop an explanation into your code.

Syntax checking runs through a single linter with three registered sources:
the TypeScript language service for JavaScript and TypeScript, the bundled
Lezer grammars for Rust, JSON, Markdown, HTML and CSS, and the bundled CPython
3.12 for exact Python `SyntaxError`. Python is registered after the grammar
pass, which stays silent on `.py`, so the interpreter's exact message wins the
de-duplication and one error never produces two messages.

rust-analyzer and the Rust standard library sources now ship inside the
bundle. The Code view does not drive them yet, so a `.rs` file still gets the
Lezer grammar and nothing more; the badge says so rather than hiding it.

## Model policy enforced against measured hardware

Only certified registry states may execute. A certified model without a
declared minimum fails closed. Download sources are restricted to HTTPS
Hugging Face paths with safe relative files. Every model in the shipped
registry is covered by an enforceable rule, and the test suite asserts it.

Minimum RAM per model is derived from measured resident footprint rather than
from arithmetic, so the catalogue does not offer a model that will fail at
load time.

| model | on disk | min RAM | measured throughput |
|---|---|---|---|
| GLM-5.2 744B (UD-IQ1_S) | 202 GB | 128 GB | 5.9 tok/s at 92 GB cache |
| Qwen3-235B-A22B (Q4_K_M) | 142 GB | 24 GB | 1.1 tok/s at 14 GB, 7.0 at 89 |
| GLM-4.5-Air 106B (Q4_K_M) | 73 GB | 32 GB | 2.7 tok/s at 14 GB, 8.2 at 67 |
| gpt-oss-120b | 65 GB | 16 GB | 4.6 tok/s at 7 GB, 19.4 at 61 |
| Llama-4 Scout 17B-16E (Q4_K_M) | 65 GB | 24 GB | 3.7 tok/s at 12 GB, 14.4 at 59 |
| Qwen3-Next-80B-A3B (Q4_K_M) | 48 GB | 16 GB | 3.8 tok/s at 1.8 GB, 22.6 at 47 |
| Qwen3-30B-A3B (Q8_0) | 32 GB | 16 GB | 11.7 tok/s at 9.8 GB, 28.7 at 31 |
| Qwen3-Coder-30B (Q8_0) | 32 GB | 16 GB | certification pending |

Every regime is bit-exact: all experts resident in cache, experts streamed
from SSD behind the cache, or CPU experts for counter-verification. There is
no fast-but-approximate mode.

## Corrections

The README announced C as a Syntax-tier language. No C grammar is bundled and
a `.c` or `.h` file opens as plain text. Corrected.

The README stated there was no rust-analyzer in the bundle. There is one now,
although the Code view does not drive it yet. Corrected, and the limit is
stated rather than implied.

The download was described as 30 MB. It is 51 MB, because of the bundled Rust
tooling. Corrected.

The skills were described as seven. They are thirty. Corrected.

## Install

Download `Galactus_0.1.3_aarch64.dmg` and drag Galactus to Applications. The
app is signed ad hoc and is not notarized, so the first launch goes through
right-click then Open. Apple Silicon only.

## Verification

199 tests pass across six suites. The thirty skills validate with no unknown
tool, no foreign tool name, no em dash and no frontmatter problem. The vault
has no unresolved link, no orphan note and no duplicate name.
